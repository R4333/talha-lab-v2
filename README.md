# Talha Turab Portfolio

TanStack Start port of the Talha Turab portfolio site.

## Commands

```bash
npm install --include=dev
npm run dev
npm run typecheck
npm run build
```

The local dev server runs at `http://localhost:3000/` by default.

## Environment

Copy `.env.example` to `.env` and set the public SEO values for the deployment:

```bash
VITE_SITE_URL=https://talhaturab.ai
VITE_SITE_NAME=Talha Turab
VITE_SITE_EMAIL=hi@talhaturab.ai
VITE_DEFAULT_OG_IMAGE=/assets/talha.jpg
```
